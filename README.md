# FDE Eval Harness（AI精度・構造化出力・コスト自動検証基盤）

プロンプトやモデルを変更した際、**必須キーワード・禁止語・JSONスキーマ準拠・推定トークンコスト（円換算）**を一括で自動検証し、デグレードを防ぐ回帰評価ハーネスです。

## 設計判断
* **0円回帰テスト**：CIやローカル環境では決定論的モックを差し込み、API課金なしで評価ロジックを検証可能。
* **AI FinOps可視化**：1ケースごとの推定トークン数とコストを算出し、精度と費用のトレードオフを定量化。

```bash
python3 -m unittest discover -s tests -v
```
